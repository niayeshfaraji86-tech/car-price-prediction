# 🚗 Car Price Prediction (Machine Learning)

A simple and clean machine learning project built with Python and Scikit-Learn to predict car prices using Linear Regression.

## 📂 Project Structure
- `j2.ipynb`: Jupyter Notebook containing data preprocessing, model training, and evaluation.
- `car_price_clean.csv`: Cleaned dataset used for the model.

## 🛠️ Libraries Used
- Python 3.x
- Pandas & NumPy (Data manipulation)
- Matplotlib & Seaborn (Data visualization)
- Scikit-Learn (Machine learning model & metrics)
